# Score Center

A guest-only board of upcoming soccer and NFL matches. Pick the leagues you follow, skip the
rest — no account, no setup.

See `CLAUDE.md` for the full developer guide (stack, data source, component map, design
rationale, deploy notes).

## Commands

```bash
npm run dev      # local dev
npm run build    # production build (verify before deploying)
npm run start    # run the production build locally
npm run lint     # eslint
```
